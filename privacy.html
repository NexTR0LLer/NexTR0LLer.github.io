Политика конфиденциальности

Действует с 7 октября 2026 года.

Media Hub — личное приложение, которое работает только на компьютере своего владельца. У него нет серверов, учётных записей и других пользователей.

Какие данные Google использует приложение

  • Доступ к Google Календарю владельца — чтобы создавать, обновлять и удалять события с датами из его библиотеки (выход серий, даты просмотра и т. п.).
  • Приложение работает только с событиями, которые создало само, и со списком календарей, чтобы владелец выбрал, куда их добавлять.

Где хранятся данные

  • Токен доступа к Google и данные библиотеки хранятся только локально, на компьютере владельца.
  • Данные никому не передаются, не продаются и не используются для рекламы или обучения моделей.
  • Использование данных, полученных через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

Как отозвать доступ

Отключить Google в приложении на странице «Подключения» или отозвать доступ в настройках аккаунта: myaccount.google.com/permissions. После этого приложение больше не обращается к календарю; созданные события остаются в календаре, пока их не удалить.

Privacy policy

Effective 7 October 2026.

Media Hub is a personal app that runs only on its owner's own computer. It has no servers, no accounts and no other users.

Google data the app uses

  • Access to the owner's Google Calendar — to create, update and delete events with dates from the owner's library (episode releases, watch dates and similar).
  • The app works only with events it created itself, and reads the list of calendars so the owner can choose where events go.

Where data is stored

  • The Google access token and library data are stored only locally, on the owner's computer.
  • Data is not shared, sold, or used for advertising or model training.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

How to revoke access

Disconnect Google on the app's Connections page, or revoke access in your Google account settings: myaccount.google.com/permissions. After that the app no longer accesses the calendar; events it created stay in the calendar until deleted.
